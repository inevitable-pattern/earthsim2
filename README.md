# 🌍 Earth History Simulator

An interactive simulation of Earth's 4.5 billion year history.

## Features

- 🌏 Globe visualization showing Earth's changing appearance
- 🌡 Real-time atmosphere composition (N₂, CO₂, O₂, CH₄...)
- 🦕 Biosphere tracking — 30+ species across 4 groups
- ⏱ Adjustable simulation speed (1x / 5x / 20x / 100x)
- 🗓 22 geological eras from Hadean to Quaternary
- 🇯🇵 Japanese / English language toggle

## Events

| Button | Effect |
|--------|--------|
| ☄ METEOR | Mass extinction, CO₂ spike |
| 🌋 VOLCANO | CO₂ surge, O₂ drop |
| ❄ ICE AGE | Global cooling, glaciation |
| ☀ WARMING | Ice melt, temperature rise |
| 💀 MASS EXT | 90% species extinction |
